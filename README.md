## Highlight Proyek

### Portfolio Web

Saya membangun dan mengembangkan halaman portfolio secara bertahap. Prosesnya dimulai dari HTML dasar, kemudian diperkuat dengan CSS, Bootstrap, SCSS, layout responsif, komponen interaktif, dan form kontak.

### Aplikasi E-Commerce PHP

## Cara Melihat Proyek

### Proyek HTML, CSS, dan JavaScript

Buka file `index.html` pada folder sesi terkait menggunakan browser.

### Proyek SQL

Jalankan file `.sql` pada folder `sesi-6` menggunakan MySQL Workbench, phpMyAdmin, atau MySQL client.

### Proyek PHP

Pastikan PHP dan MySQL sudah terpasang, lalu jalankan server dari folder proyek yang ingin digunakan:

```bash
cd sesi-9
php -S localhost:8000
```

Kemudian buka `http://localhost:8000` pada browser. Untuk sesi 8 dan 9, import file `database.sql` terlebih dahulu dan sesuaikan kredensial database pada `koneksi.php`.
